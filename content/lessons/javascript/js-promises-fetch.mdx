Some work takes time: downloading data from a server might take a second or more. JavaScript does not freeze the page while it waits. Instead, slow operations hand you a **promise**: an object that stands for a value that is not ready *yet*. This lesson shows how to wait for promises, and how to use `fetch` to load real data from the internet.

## What a promise is

A promise is like an order receipt at a counter. You get it immediately, and later it is either **fulfilled** (here is your food) or **rejected** (sorry, we are out). Here is a promise we make ourselves with `new Promise`, using `setTimeout` from the Callbacks lesson to fake a slow task:

```js-live
function wait(ms) {
  return new Promise((resolve) => {
    setTimeout(() => resolve(`Done after ${ms}ms`), ms);
  });
}

console.log("Ordering...");
const promise = wait(1000);
console.log(promise); // a Promise, not the message: it is not ready yet

promise.then((message) => {
  console.log(message);
});

// Try changing 1000 to 3000.
```

`resolve` is a function the promise gives you. Calling it fulfills the promise with a value. `.then(callback)` says "when the value is ready, call this with it."

## async and await

Chaining `.then` works, but there is a more readable way. Inside a function marked `async`, the keyword `await` pauses *that function* until a promise settles and gives you its value directly:

```js-live
function wait(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

async function countdown() {
  console.log("3");
  await wait(1000);
  console.log("2");
  await wait(1000);
  console.log("1");
  await wait(1000);
  console.log("Go!");
}

countdown();
console.log("This prints right after 3, without waiting.");

// Try adding another step to the countdown.
```

Only the `async` function waits. Code outside it carries on, so the page stays responsive.

## Fetching data

`fetch(url)` requests a URL and returns a promise. It takes two waits: one for the response to arrive, and one to read its body as JSON (data shaped like JavaScript objects and arrays):

```js-live
async function loadTodo() {
  const response = await fetch("https://jsonplaceholder.typicode.com/todos/1");
  const todo = await response.json();

  console.log(todo);
  console.log(`"${todo.title}" done? ${todo.completed}`);
}

loadTodo();

// Try changing /todos/1 to /todos/2.
```

The result is an ordinary object, so everything from the Objects, map, and filter lessons applies:

```js-live
async function loadUsers() {
  const response = await fetch("https://jsonplaceholder.typicode.com/users");
  const users = await response.json();

  const names = users.map((user) => user.name);
  console.log(names);
  console.log(`Loaded ${users.length} users`);
}

loadUsers();

// Try using filter to keep only users whose name includes "C".
```

## Handling errors

Networks fail. Wrap awaited code in `try`/`catch`: if anything inside `try` throws or a promise rejects, JavaScript jumps to `catch`. Note that `fetch` only rejects when the request cannot happen at all; a "404 Not Found" still arrives as a response, so check `response.ok` yourself:

```js-live
async function loadSafely(url) {
  try {
    const response = await fetch(url);
    if (!response.ok) {
      throw new Error(`Server said ${response.status}`);
    }
    const data = await response.json();
    console.log("Got data:", data);
  } catch (error) {
    console.log("Something went wrong:", error.message);
  }
}

loadSafely("https://jsonplaceholder.typicode.com/todos/1");
loadSafely("https://jsonplaceholder.typicode.com/not-a-real-page");

// Try a URL that does not exist at all, like "https://no-such-site.invalid".
```

<Note>
In React, data loading usually happens inside an effect (`useEffect`): the component shows "Loading..." first, starts a `fetch`, and when the data arrives it stores it in state, which makes React show it. Every piece you need for that is in this lesson: `async`, `await`, `response.json()`, and `try`/`catch`.
</Note>

## Recap

- A promise stands for a value that will be ready later, or an error.
- `new Promise((resolve) => ...)` makes one; `.then` runs code when it is ready.
- Inside an `async` function, `await` waits for a promise and gives you its value.
- `fetch(url)` returns a promise of a response; `await response.json()` reads the data.
- Use `try`/`catch` and check `response.ok` to handle failures.
