Lay out a small blog with semantic elements. Each blog post should be able to stand on its own, while the "About the Author" part is just one section of the page.

## Requirements

- A page `<header>` with the heading (`<h1>`) `Dev Diary`.
- A `<main>` after the header that contains:
  - Two `<article>` elements, one per post. The first has the heading (`<h2>`) `Learning HTML`, and the second has the heading `My First Form`. Each post also needs at least one paragraph.
  - A `<section>` with the heading (`<h2>`) `About the Author` and a short paragraph. It is **not** a blog post, so it must not be inside an `<article>`.
- A page `<footer>` after `<main>` with any closing text, like a copyright line.

## Hints

- Ask of each part: "Could this be shared on its own and still make sense?" If yes, it is an `<article>`. If it is just one part of the page, it is a `<section>`.
- Only use `<div>` if nothing else describes the content. This page does not need any.
