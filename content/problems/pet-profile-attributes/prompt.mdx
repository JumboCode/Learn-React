Make a profile page for a pet (real or imaginary), using attributes to name and describe its elements.

## Requirements

- A top-level heading (`<h1>`) with the pet's name. Give it the attribute `id="pet-name"`.
- An image (`<img>`) of the pet with a `src` and a non-empty `alt` that describes what the picture shows. Any image address works, for example `https://picsum.photos/id/237/300/200`.
- At least **three** paragraphs (`<p>`) with facts about the pet. Give each of them `class="fact"`.
- Exactly **one** of those fact paragraphs should also have the class `favorite`, so it has both classes: `class="fact favorite"`.

## Hints

- Attributes go inside the **opening** tag as `name="value"` pairs.
- An `id` must be unique on the page, but a `class` can be reused on as many elements as you like.
- An element can have several classes, separated by spaces.
