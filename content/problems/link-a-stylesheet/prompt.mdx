This page has a stylesheet, `styles.css`, but the page never loads it, so none of its styles show up. Connect the two files, then finish the stylesheet.

## Requirements

- In `index.html`, add a `<link>` tag inside `<head>` that loads `styles.css` (use `rel="stylesheet"` and `href="styles.css"`).
- In `styles.css`, write these rules:
  - `body`: set `background-color` to `lightyellow`.
  - `h1`: set `color` to `navy` and `font-size` to `40px`.
  - `p`: set `color` to `gray`.

## Hints

- A rule looks like `selector` followed by curly braces containing `property: value;` pairs.
- The `<link>` tag has no closing tag.
