Practice writing **arrow functions**. Every function in this problem must be an arrow function stored in an exported `const`, like `export const square = (n) => n * n;`.

## Requirements

- `double(n)` returns `n` times 2. The starter writes it with `function`; rewrite it as an arrow function.
- `add(a, b)` returns the sum of `a` and `b`. Rewrite it as an arrow function too.
- `shout(text)` returns `text` in uppercase followed by `"!"`. The starter version has a bug: it always returns `undefined`. Find and fix it.
- `fullName(first, last)` returns the first and last name joined by one space.

## Examples

| Call | Returns |
| --- | --- |
| `double(21)` | `42` |
| `add(2, 3)` | `5` |
| `shout("hello")` | `"HELLO!"` |
| `fullName("Ada", "Lovelace")` | `"Ada Lovelace"` |

## Hints

- `"hi".toUpperCase()` gives `"HI"`.
- Remember the braces trap: once you put curly braces around an arrow function's body, you need `return`.
