Turn a plain block of text into a neat profile card using the **box model**: padding inside, a border around it, and margin outside. Only edit `styles.css`.

## Requirements

- `.card`:
  - `box-sizing` is `border-box`, so its `width` includes the padding and border.
  - `width` is `300px`.
  - `padding` is `24px` on all four sides.
  - A `2px solid steelblue` border on all four sides, written with the `border` shorthand.
  - `border-radius` is `8px`.
  - Centered horizontally: `margin-left` and `margin-right` are both `auto`, and `margin-top` is `32px`.
- `.card h2`: `margin-top` is `0`.

## Hints

- Shorthands save typing: `padding: 24px;` sets all four sides, and `margin: 32px auto 0;` sets the top, then left and right, then the bottom.
- The `border` shorthand takes a width, a style, and a color.
