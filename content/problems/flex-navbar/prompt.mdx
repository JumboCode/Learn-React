Build a classic navigation bar with **flexbox**: the logo on the left, the links on the right, everything lined up in the middle. Only edit `styles.css`.

## Requirements

- `.navbar` (the outer `<nav>`):
  - `display` is `flex`.
  - `justify-content` is `space-between`, which pushes the logo and the links to opposite ends.
  - `align-items` is `center`.
  - `padding` is `16px` on all four sides.
- `.nav-links` (the list of links):
  - `display` is `flex`, so the links sit in a row.
  - `gap` is `24px`.

## Hints

- `justify-content` spaces items along the row; `align-items` lines them up across it.
- Only direct children become flex items, so the links need their own flex container.
