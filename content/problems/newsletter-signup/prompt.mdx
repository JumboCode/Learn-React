Build a small newsletter sign-up form, with every field properly labelled.

## Requirements

- A `<form>` that contains everything below.
- An email input (`type="email"`) labelled `Email address`.
- A checkbox labelled `Send me weekly updates`. It should start **checked**.
- A submit button with the text `Subscribe`.

## Hints

- Connect a `<label>` to its input by giving the input an `id` and the label a matching `for`.
- For a checkbox, the label usually comes after the input.
- The `checked` attribute has no value: just writing `checked` is enough.
