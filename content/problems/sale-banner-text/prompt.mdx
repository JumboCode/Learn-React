Style an eye-catching sale banner using colors, fonts, and text properties. Only edit `styles.css`.

## Requirements

- `.banner`:
  - `background-color` is `tomato`.
  - `color` is `white`.
  - `text-align` is `center`.
  - `font-family` is `Georgia, serif`.
- `.banner h1`: `font-size` is `2.5rem`.
- `.tagline`: `font-weight` is `bold` and `font-size` is `20px`.
- `.fine-print`: `font-size` is `12px` and `color` is `#ffe4e1` (a pale pink).

## Hints

- `color`, `text-align`, and `font-family` are **inherited**: set them once on `.banner` and the text inside picks them up.
- `2.5rem` means 2.5 times the root font size (16px), so 40px.
