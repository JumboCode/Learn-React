A café's menu page is all plain black text. Use the right **selectors** to style it. The HTML is finished and read-only: only edit `styles.css`.

## Requirements

- Every `h2` heading: `color` is `darkgreen`.
- Every element with the class `price`: `font-weight` is `bold`.
- The one element with the id `special`: `background-color` is `gold`.
- Links **inside the `nav`** only: `text-decoration` is `none`. The link in the footer must keep its underline, so don't style every `a`.
- The **first** `li` in each menu list: `font-style` is `italic`. Other list items must not be italic.

## Hints

- `.name` selects by class and `#name` selects by id.
- A space between selectors means "inside": `parent child`.
- The `:first-child` pseudo-class matches an element that is the first child of its parent.
