Write two functions that convert temperatures, and **export** them so the tests can call them.

## Requirements

- `celsiusToFahrenheit(celsius)` returns the temperature in Fahrenheit, using `F = C × 9 / 5 + 32`.
- `fahrenheitToCelsius(fahrenheit)` returns the temperature in Celsius, using `C = (F − 32) × 5 / 9`.
- Both functions must **return** the number. Logging it with `console.log` is not enough.

## Examples

| Call | Returns |
| --- | --- |
| `celsiusToFahrenheit(100)` | `212` |
| `celsiusToFahrenheit(-40)` | `-40` |
| `fahrenheitToCelsius(32)` | `0` |

Use `console.log` to try your functions; the output appears in the console panel.
