Build a small page of useful links, plus a picture that is also a link.

## Requirements

- A top-level heading (`<h1>`) with the text `My Favorite Sites` and the attribute `id="top"`.
- A link with the text `MDN Web Docs` that goes to `https://developer.mozilla.org` and opens in a **new tab**.
- A link with the text `Email me` whose address starts with `mailto:` (use any email address).
- An image that is itself a link to `https://en.wikipedia.org/wiki/Mountain`. Give the image the alt text `Read about mountains on Wikipedia`. Any image `src` works, for example `https://picsum.photos/id/29/300/200`.
- A link with the text `Back to top` that jumps to the heading on this same page.

## Hints

- `target="_blank"` opens a link in a new tab.
- An address that starts with `#` points at the element on the same page with that `id`.
- To make an image clickable, put the `<img>` *inside* the `<a>`. Its alt text then describes where the link goes.
